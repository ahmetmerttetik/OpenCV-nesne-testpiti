# Teknofest Hava Savunma - Görüntü İşleme 🚀

Bu proje, **Teknofest Hava Savunma** yarışması kapsamında geliştirilen nesne tespit sistemini içermektedir.

### 🎯 Proje Özellikleri
* **Nesne Tespiti:** YOLOv8 ve HSV tabanlı görüntü işleme teknikleri kullanıldı.
* **Hava Savunma:** Gerçek zamanlı hedef takibi ve tespiti üzerine odaklanıldı.

### 🛠️ Kurulum (Sanal Ortam)
Projeyi çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. **Sanal ortam oluştur:** `python -m venv venv`
2. **Aktif et:** `venv\Scripts\activate` (Windows) veya `source venv/bin/activate` (Linux)
3. **Kütüphaneleri yükle:** `pip install -r requirements.txt`
